## 一、jsBridge文件系统集成

### 官方SDK替换手写SDK

- **问题**：之前使用手写的jsBridge封装代码，在一门APP中无法正常工作
- **根因**：手写代码没有完整覆盖所有场景和边界情况
- **方案**：直接使用一门官方SDK `public/jsbridge-mini.js`，通过全局变量 `jsBridge` 访问
- **关键文件**：
  - `public/jsbridge-mini.js` - 官方SDK文件
  - `index.html` - 引入SDK
  - `src/utils/fsService.js` - 文件系统服务封装

```javascript
// fsService.js - 官方SDK使用方式
import { jsBridge } from '@/utils/jsBridge';

// 确保在APP环境中
if (!jsBridge.isInApp()) {
  console.log('不在APP中，跳过jsBridge调用');
  return;
}

// 使用官方API
const result = await jsBridge.fs.readFile({
  path: filePath,
  encoding: 'base64'
});
```

### 虚拟时光图片上传流程

- **问题**：虚拟时光页面需要上传图片到一门APP的文件系统
- **方案**：4步流程
  1. 用户选择本地图片（file input）
  2. 读取为base64
  3. 调用 `jsBridge.fs.writeFile` 保存到APP指定目录
  4. 返回路径存储到IndexedDB

```javascript
// 图片上传核心逻辑
const handleImageUpload = async (file) => {
  const reader = new FileReader();
  const base64 = await new Promise((resolve) => {
    reader.onload = (e) => resolve(e.target.result.split(',')[1]);
    reader.readAsDataURL(file);
  });
  
  const fileName = `virtual_${Date.now()}.jpg`;
  const appPath = `/sdcard/Pictures/BabyDiary/${fileName}`;
  
  await jsBridge.fs.writeFile({
    path: appPath,
    data: base64,
    encoding: 'base64'
  });
  
  return appPath;
};
```

## 二、数据层修复经验

### 导出/导入缺失虚拟时光内容

- **问题**：导出数据时虚拟时光内容丢失，导入后虚拟时光为空
- **根因**：`exportService.js` 和 `importService.js` 没有处理 `virtualTimeContents` 表
- **方案**：在导出时增加 `virtualTimeContents` 表的导出，导入时区分新增和更新

```javascript
// exportService.js - 导出虚拟时光
const virtualTimeContents = await getAllFromStore('virtualTimeContents');
exportData.virtualTimeContents = virtualTimeContents;

// importService.js - 导入虚拟时光
for (const item of data.virtualTimeContents || []) {
  const existing = await getByIdFromStore('virtualTimeContents', item.id);
  if (existing) {
    await updateInStore('virtualTimeContents', item.id, item);
  } else {
    await addToStore('virtualTimeContents', item);
  }
}
```

### addVirtualTimeContent 漏存 title/emoji

- **问题**：创建虚拟时光内容时，title和emoji字段没有保存到数据库
- **根因**：service层方法只保存了部分字段

const addVirtualTimeContent = async (content) => {

## 三、时区处理经验

### 时区偏移导致日期显示昨天

- **问题**：时光轴上的日期比实际日期少一天
- **根因**：JavaScript的`Date`对象在一天开始时(00:00)可能因为时区偏移导致日期计算错误
- **方案**：
  1. 使用UTC日期进行计算，避免时区影响
  2. 时光轴分组时用UTC日期比较

```javascript
// 时光轴日期分组 - 修正时区问题
const getUTCMidnight = (timestamp) => {
  const date = new Date(timestamp);
  return Date.UTC(date.getFullYear(), date.getMonth(), date.getDate());
};

// 日期显示 - 添加时区补偿
const formatDateWithOffset = (timestamp) => {
  const localOffset = new Date().getTimezoneOffset() * 60000;
  const adjusted = timestamp + localOffset;
  return formatDate(new Date(adjusted));
};
```

## 四、性能优化经验

### 时光轴下滑闪烁修复

- **问题**：时光轴页面下滑时出现闪烁，虚拟滚动和轮询同时存在导致冲突
- **根因**：
  1. 虚拟滚动重新渲染大量DOM元素
  2. 轮询(polling)同时在更新数据，导致状态冲突
  3. 数据量大时渲染性能差

- **方案**：
  1. **增加数据缓存**：已渲染的日期分组合并，新数据只追加不重渲染
  2. **优化轮询频率**：使用`cancelAnimationFrame`或`setTimeout`控制更新节奏
  3. **虚拟滚动优化**：`react-window`的`VariableSizeList`动态高度处理
  4. **懒加载图片**：图片延迟加载，减少首屏渲染压力

```javascript
// 时光轴渲染优化
const TimelineList = ({ moments }) => {
  const [cachedGroups, setCachedGroups] = useState([]);
  const rafRef = useRef(null);
  
  useEffect(() => {
    // 取消之前的更新请求
    if (rafRef.current) {
      cancelAnimationFrame(rafRef.current);
    }
    
    // 使用RAF批量更新
    rafRef.current = requestAnimationFrame(() => {
      const newGroups = groupMomentsByDate(moments);
      setCachedGroups(prev => mergeGroups(prev, newGroups));
    });
    
    return () => {
      if (rafRef.current) cancelAnimationFrame(rafRef.current);
    };
  }, [moments]);
  
  return <VariableSizeList items={cachedGroups} />;
};
```

### 示例模板图片加载失败兜底

- **问题**：示例模板中的图片URL可能失效或加载失败
- **方案**：
  1. 每张图片有默认placeholder
  2. `onError`时切换到备用URL
  3. 支持用户自己替换/删除/添加图片

```javascript
const ImageWithFallback = ({ src, alt, onReplace, onDelete }) => {
  const [currentSrc, setCurrentSrc] = useState(src);
  const [errorIndex, setErrorIndex] = useState(0);
  
  const fallbackUrls = [
    src,
    `https://picsum.photos/seed/${alt}/400/300`,
    '/placeholder-image.png'
  ];
  
  const handleError = () => {
    if (errorIndex < fallbackUrls.length - 1) {
      setErrorIndex(prev => prev + 1);
      setCurrentSrc(fallbackUrls[errorIndex + 1]);
    }
  };
  
  return (
    <div className="relative group">
      <img
        src={currentSrc}
        alt={alt}
        onError={handleError}
        className="w-full h-40 object-cover rounded-lg"
      />
      <div className="absolute inset-0 bg-black/50 opacity-0 group-hover:opacity-100 
                      flex items-center justify-center gap-2 transition-opacity">
        <button onClick={onReplace}>替换</button>
        <button onClick={onDelete}>删除</button>
        <button>添加</button>
      </div>
    </div>
  );
};
```

### 退出登录后记住身份自动登录

- **问题**：用户退出后重新打开需要重新登录，体验不佳
- **方案**：使用localStorage记住身份信息，支持快速重新登录

```javascript
// 退出登录但保留身份
const logout = (keepIdentity = true) => {
  if (keepIdentity) {
    // 保存身份信息到localStorage
    const currentUser = getCurrentUser();
    localStorage.setItem('remembered_identity', JSON.stringify({
      userId: currentUser.id,
      email: currentUser.email,
      identity: currentUser.identity,
      role: currentUser.role
    }));
  }
  
  // 清除session但不清除缓存数据
  localStorage.removeItem('currentUser');
  navigate('/login');
};

// 应用启动时检查自动登录
const checkAutoLogin = () => {
  const remembered = localStorage.getItem('remembered_identity');
  if (remembered) {
    const identity = JSON.parse(remembered);
    setCurrentUser(identity);
    return true;
  }
  return false;
};
```

## 七、时光轴日期分组重构

### 基于宝宝生日的相对时间显示

- **功能**：时光轴分组从绝对日期改为相对时间显示
- **显示规则**：
  - 今天
  - 昨天
  - X天前
  - X周前
  - X个月前
  - Y年Z个月前（超过1年）

- **计算逻辑**：

```javascript
const getRelativeTimeDisplay = (timestamp, babyBirthday) => {
  const now = new Date();
  const target = new Date(timestamp);
  const birth = new Date(babyBirthday);
  
  const diffMs = target - birth;
  const diffDays = Math.floor(diffMs / (1000 * 60 * 60 * 24));
  
  if (diffDays === 0) return '第1天';
  if (diffDays === 1) return '第2天';
  if (diffDays < 7) return `第${diffDays + 1}天`;
  if (diffDays < 14) return '第2周';
  if (diffDays < 30) return `第${Math.floor(diffDays / 7) + 1}周`;
  if (diffDays < 365) return `第${Math.floor(diffDays / 30) + 1}个月`;
  
  const years = Math.floor(diffDays / 365);
  const months = Math.floor((diffDays % 365) / 30);
  return `${years}岁${months}个月`;
};
```

## 经验教训总结

1. **数据层修复要彻底**：addVirtualTimeContent等核心方法补全字段后，要同步检查相关调用的参数
2. **时区问题尽早处理**：日期计算从一开始就要考虑时区，特别是涉及宝宝生日的相对时间
3. **性能优化要有策略**：虚拟滚动+轮询组合时要仔细协调，避免状态冲突
4. **示例数据要健壮**：图片URL要有多级兜底，用户能手动替换
5. **身份系统要考虑恢复**：退出登录时保留身份信息，提升用户体验
6. **分享功能要兜底**：图片和标题都要有默认值，避免分享失败
