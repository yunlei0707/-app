项目 说明
操作者 你

客服方式 微信 / QQ / 邮件（一对一）
预计完成时间 1–3 小时（含熟悉过程）

📋 通用准备工作（两个工作流都需要）

步骤 DIY-01：注册 GitHub（免费）
  • 打开 https://github.com
  • 点击右上角 Sign up
  • 输入：邮箱、密码、用户名（建议英文 / 数字组合）
  • 完成拼图验证和邮箱验证
  • 登录 GitHub
步骤 DIY-02：注册 Vercel（免费）
  • 打开 https://vercel.com
  • 点击 Sign up
  • 选择 Continue with GitHub
  • 授权 Vercel 读取你的 GitHub 账号
  • 选择 Skip（跳过团队创建）
  • 完成注册
步骤 DIY-03：准备源文件
  • 我会把完整的网站源文件发给你（ZIP 压缩包）
  • 包含所有 HTML / CSS / JS / 图片等
  • 下载到电脑并解压，确认你能看到类似 index.html 的文件

🛠️ 工作流 1：由我提供域名（你不需要买域名）

特点：使用我提供的子域名（例如 你的项目名.我的域名.com），最省事

步骤 DIY-W1-01：创建 GitHub 仓库
  • 登录 GitHub
  • 点击左上角 + → New repository
  • 填写：Repository name（如 myweb）、Public / Private 选 Public
  • 不要勾选 "Add a README"
  • 点击 Create repository
步骤 DIY-W1-02：上传源文件到 GitHub
  • 在刚创建的仓库页面，点击 Add file → Upload files
  • 把解压后的所有源文件拖进去
  • 下方写 first commit
  • 点击 Commit changes
步骤 DIY-W1-03：在 Vercel 部署网站
  • 打开 https://vercel.com
  • 点击 Add New… → Project
  • 在 Import Git Repository 中：找到你刚创建的仓库，点击 Import
  • 保持所有默认设置（不用改）
  • 点击 Deploy
  • 等待 30–60 秒
步骤 DIY-W1-04：确认部署成功
  • 部署完成后，Vercel 会显示 Congratulations
  • 点击 Visit 按钮
  • 网页应该正常打开
步骤 DIY-W1-05：等待我绑定子域名
  • 我会把我提供的子域名手动绑定到你的 Vercel 项目
  • 等待 5–10 分钟，然后访问我给的新域名确认可用
步骤 DIY-W1-06：一门APP打包成APP
  • 打开一门APP官网（我会给你网址）
  • 注册 / 登录
  • 点击 生成APP
  • 输入你的网站地址
  • 配置应用名称、图标
  • 点击生成
  • 下载 Android APK / iOS IPA
步骤 DIY-W1-07：安装并使用 ✅

🛠️ 工作流 2：你提供域名（自己买域名）

特点：用你自己的品牌域名，完全自主可控

核心差异提醒

相对于工作流 1，只有两个地方不同：需要买域名、需要做 DNS 解析，其他步骤完全相同

步骤 DIY-W2-01：购买域名（Namesilo）
  • 打开 https://www.namesilo.com
  • 搜索你想要的域名
  • 加入购物车 → 付款（支持支付宝）
  • 登录域名管理后台
步骤 DIY-W2-02：GitHub 创建仓库 + 上传文件（同 W1-01/W1-02）
步骤 DIY-W2-03：Vercel 部署网站（同 W1-03/W1-04）
步骤 DIY-W2-04：绑定你自己的域名
  • 在 Vercel 项目页面，点击 Settings
  • 左侧菜单选择 Domains
  • 输入你的域名
  • 点击 Add
步骤 DIY-W2-05：去 Namesilo 做 DNS 解析
  • 登录 Namesilo
  • 进入 Domain Manager
  • 点击你的域名 → DNS Records
  • 添加 CNAME / A 记录
步骤 DIY-W2-06：等待解析生效（5-30分钟）
步骤 DIY-W2-07：一门APP打包
步骤 DIY-W2-08：安装使用 ✅
