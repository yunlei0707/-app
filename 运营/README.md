## ⚠️ 法律风险规避注意事项

### 竞品名称必须模糊化处理：

| 真实名称 | 模糊代称（必须使用） |
|---------|---------------------|
| 时光小屋 | ✅ 某光小屋 |
| 亲宝宝 | ✅ 某宝宝 |
| 宝宝树 | ✅ 某育儿APP |

### 其他注意事项
1. **新闻引用**：只提来源，不做主观评价
2. **功能承诺**：避免绝对化用词
3. **价格对比**：基于公开可查定价
4. **截图使用**：必须打码处理
